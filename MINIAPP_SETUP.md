# 🚀 Інструкція по розгортанню Mini App для Paro Bot

## 📋 Що було створено

### 1. **Mini App (Веб-інтерфейс)**
- `webapp/app.py` - Flask сервер з API
- `webapp/templates/index.html` - HTML/CSS/JS інтерфейс
- `webapp/requirements.txt` - Залежності Python

### 2. **Модифікований бот**
- Додано імпорт `WebAppInfo` 
- Додано переклади для Mini App
- Додано команду `/webapp`
- Модифіковано команду `/start` з кнопкою Mini App

## 🛠️ Встановлення

### Крок 1: Встановлення залежностей для веб-додатку
```bash
cd webapp
pip install -r requirements.txt
```

### Крок 2: Створення додаткових таблиць БД
```bash
python setup_db.py
```

### Крок 3: Налаштування URL Mini App
1. Відредагуйте `parobot1.1.py`, замініть:
   ```python
   WEBAPP_URL = "https://yourdomain.com"  # Замініть на реальний URL
   ```

2. Відредагуйте `webapp/app.py`, перевірте шляхи до БД:
   ```python
   DB_PATH = '../shop.db'  # Шлях до бази даних бота
   PHOTOS_PATH = '../photos'  # Шлях до фото товарів
   ```

## 🌐 Розгортання на сервері

### Варіант 1: Localhost (для тестування)
```bash
cd webapp
python app.py
```
Mini App буде доступний на `http://localhost:5000`

### Варіант 2: Продакшн (Timeweb Cloud)
1. Завантажте папку `webapp` на сервер
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть через Gunicorn:
   ```bash
   gunicorn -w 4 -b 0.0.0.0:5000 app:app
   ```

### Варіант 3: Nginx + Gunicorn
1. Налаштуйте Nginx:
   ```nginx
   server {
       listen 80;
       server_name yourdomain.com;
       
       location / {
           proxy_pass http://127.0.0.1:5000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
       
       location /static/photos/ {
           alias /path/to/your/photos/;
       }
   }
   ```

2. Запустіть Gunicorn:
   ```bash
   gunicorn -w 4 -b 127.0.0.1:5000 app:app
   ```

## 🔧 Налаштування Telegram Bot

### 1. Встановіть Mini App в BotFather
1. Відкрийте @BotFather
2. Виберіть `/mybots` → Ваш бот → `Bot Settings` → `Menu Button`
3. Встановіть:
   - **Text**: "🛍️ Магазин"
   - **URL**: `https://yourdomain.com`

### 2. Оновіть WEBAPP_URL в коді
Замініть `https://yourdomain.com` на реальний URL вашого сервера.

## 📱 Функціональність Mini App

### ✨ Можливості
- 🗂️ **Каталог категорій** з красивими карточками
- 🛍️ **Перегляд товарів** з фото, описом, ціною
- 🛒 **Кошик** з можливістю зміни кількості
- 📝 **Оформлення замовлення** з усіма полями
- 🌍 **Мультимовність** (Українська, Польська, Російська)
- 📱 **Адаптивний дизайн** під мобільні пристрої
- 🎨 **Telegram тема** (підтримка темного/світлого режиму)

### 🔄 Інтеграція з ботом
- Заказы з Mini App потрапляють в ту ж БД
- Адміни отримують сповіщення в Telegram
- Підтримка тих самих способів доставки та оплати
- Збереження профілів користувачів

## 🛡️ Безпека
- Валідація всіх даних на сервері
- Перевірка наявності товарів
- Захист від SQL-ін'єкцій
- Telegram WebApp валідація користувачів

## 🧪 Тестування

### Локальне тестування
1. Запустіть Flask додаток локально
2. Використайте ngrok для тунелю:
   ```bash
   ngrok http 5000
   ```
3. Встановіть ngrok URL в WEBAPP_URL
4. Протестуйте в Telegram

## 📞 Підтримка

Якщо виникли проблеми:
1. Перевірте логи Flask додатку
2. Перевірте БД з'єднання
3. Переконайтеся, що шляхи до файлів правильні
4. Перевірте доступність URL з Telegram
